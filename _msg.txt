## 修复：_find_python.bat 向上搜索会死循环

工具独立成库后（不在 OAS 目录树内，上方没有 toolkit\），`:walk` 循环
会一直转到盘符根并卡死，导致双击毫无反应。

根因：`for %%I in ("%DIR%..") do set "PARENT=%%~fI"` 对盘符根
返回的是 `X:\`（带尾反斜杠），而 `DIR` 也是 `X:\`，于是
`set "DIR=%PARENT%\"` 得到 `X:\\`，`PARENT == DIR` 永远不成立 → 死循环。

修法：剥掉尾反斜杠后判断是否形如 `X:`，是则停止；另加 32 次上限兜底。

## 修复：pythonw 在 PATH 分支找不到

原来 PATH 分支只处理 `python`，`pythonw` 直接失败。默认安装的 Python
通常只有 python.exe，导致 app 模式起不来。补上 pythonw → python →
pyw 的降级链。

## 修复：vbs 编码导致中文路径乱码

vbs 是 UTF-8 无 BOM 存的，WSH 按系统 ANSI 代码页（中文 = GBK）解析，
中文路径全变乱码，`FileExists` 找不到 bat，双击弹一个乱码错误框。
改为 UTF-16LE + BOM（WSH 原生支持）。

## 修复：关闭脚本 pause 让人以为卡住

去掉结尾的 `pause`，关闭后直接退出。
