# OAS 账号列表管理工具

给 OAS 的多账号列表做增删改排序：协战、切号、勾协三个列表都能整表重排、批量导入、导出 JSON。

OAS 面板本身只能「数量 +1 再在末尾填一张空卡」，没法在中间插队、删除或重排。这个工具直接把整个列表读出来，在内存里改完再按新顺序整表写回。

---

## 快速开始

### 1. 需要 Python

任选其一：

- 系统已装 Python 3.8+（PATH 里有 `python`）
- 在工具目录放一份便携版到 `python\`（`python.exe` + `pythonw.exe`）
- 用 OAS 自带的 `toolkit\python.exe`（放在工具目录或任一上层目录）

### 2. 告诉它 OAS 在哪

工具是独立的，需要知道要改哪个 OAS 目录（**该目录下要有 `config\`**）。三种方式任选：

```powershell
# A. 命令行（临时）
python server.py --root "D:\你的OAS目录"

# B. 环境变量（设一次，以后双击启动器也生效）
setx OAS_ROOT "D:\你的OAS目录"

# C. 直接启动，再在页面右上角「切换目标」里填路径（会记住）
```

`--root` 也可以直接指到 `config` 目录本身，会自动取上一级。

### 3. 启动

**双击根目录的 `启动账号管理（独立窗口）.lnk`** —— 打开一个没有地址栏的独立窗口，像桌面应用。

想放桌面：右键这个 `.lnk` → 发送到 → 桌面快捷方式。

### 4. 退出

页面右下角「退出工具」，或双击 `关闭账号管理.bat`。

## 界面怎么用

| 操作 | 怎么点 |
| --- | --- |
| **排序** | 顶部「自动排序」按钮，按「排序方式」下拉执行 |
| **拖拽调整** | 按住卡片左侧 `⠿` 拖动；落点显示蓝线（卡片上半 = 插到前面，下半 = 插到后面） |
| **中间插队** | 鼠标移到两张卡片之间，出现「＋ 插入到第 N 位」 |
| **删除 / 上下移** | 卡片右侧「删除」/ ↑ ↓ |
| **编辑** | 点卡片正文，改角色名、服务器、账号、别名、平台 |
| **切换视图** | 「☰ 列表」（信息全）/「▦ 方块」（紧凑），选择会记住 |
| **每行几张卡** | 方块视图下可选「自动 / 2 / 3 / 4 / 6 / 8」，选择会记住 |
| **复制摘要** | 卡片右侧「⧉」，复制「区服-角色名-勾协类型」 |
| **保存** | 底部「保存」，写盘前自动备份 |
| **放弃修改** | 底部「放弃修改」 |

### 批量导入

点「批量粘贴导入」，从 Excel 直接复制粘贴即可，**不用管列顺序**：

```
iOS	i154	雅乐之邦	紫星一号
iOS	i154	花火之夏	紫星二号
```

- 第一列是平台（iOS/安卓）→ 按 `平台, 账号, 服务器, 角色名[, 别名]` 解析
- 第一列是其他 → 按 `账号, 服务器, 角色名[, 别名][, 平台]` 解析
- 账号格里可用逗号挂别名：`i154,小号1,小号2` → 别名存成 `小号1#小号2`
- 勾选**「使用共同值」**可以只写角色名，账号/服务器/平台填一次自动补
- 点「预览识别结果」确认列没认错，再点「导入」

### 导出 JSON

顶部「导出 JSON」，复制或下载**未脱敏**的完整任务配置（含账号信息，分享注意）。

### 勾协类型筛选

| 选项 | 含义 |
| --- | --- |
| 全部 | 所有账号 |
| 无勾 / 普勾 / 现勾 | **只算本周期**查出来的 |
| 勾协已过期 | 查过，但结果是上个周期的 |
| 从未查找 | 还没查过 |

过期的不计入任何类型 —— 上个周期是普勾不代表现在是。

## 三个列表的差别

| 目标任务 | 列表 | 计数字段 |
| --- | --- | --- |
| `assist_battle`（一键协战） | `account_list_N` | `assist_battle_config.account_count` |
| `account_switch`（切号执行任务） | `account_list_N` | `account_switch_config.switch_account_count` |
| `find_jade`（寻勾协小号） | `sup_account_list_N` | `find_jade_config.sup_account_count` |

**切号任务多一个 `current_index` 轮换指针**（下一个该切哪个号，0 开始）。删号或重排后指针可能指错人，所以：

- 界面上会显示「下次切到第几个号、是哪个角色」
- 保存时指针**越界自动归零**，在范围内则不动它

## 局域网（另一台机器上的 OAS）

把共享目录加为预设即可：

```
\\主机名\共享名
```

⚠️ 注意：

- **改配置前先停掉那台机器上的 OAS**，否则它会回写覆盖你的修改
- 备份落在**你本机**的 `backups\`，那台机器不会有
- 网络断开时保存会失败，但不会留半截文件（原子写入），重试即可

### 读不到配置（Permission denied）

Linux/Samba 共享上常见。原因是 OAS 保存配置时用 `tempfile.mkstemp()`（固定创建 0600）+ rename 覆盖，所以它每写一次，文件权限就变回 `600`。

**临时解决**（撑到 OAS 下次写入）：

```bash
chmod 644 <config目录>/*.json
```

**持久解决**（在共享那台机器上，二选一）：

```ini
# A. 让 Samba 以 OAS 的属主身份访问（推荐）
# smb.conf 的该共享段里加：
force user = <OAS运行用户>
```

或者改 OAS 的写入方式，让临时文件创建后 `chmod 0644`。

## 常用命令

```powershell
# 独立窗口
python -B server.py --app

# 普通浏览器
python -B server.py

# 指定端口
python -B server.py --port 22300

# 停止正在运行的实例
python -B server.py --stop

# 自检（21 项）
node run-all-checks.js
```

默认端口 **22299**。重复启动会复用已有实例，不会起多个。

## 改了工具代码后必须重启

`server.py` 在启动时就把 `ui.html` / `app.js` / `core.js` / `ui.css` 读进内存了，改前端文件后**必须重启工具**才会生效（刷新页面没用）。

---

## 安全措施

1. **写前备份**：每次保存前把原文件复制到 `backups\{配置}.{时间戳}.json`
2. **原子写入**：临时文件 + `os.replace`，中途失败不会留半个文件
3. **并发冲突保护**：加载时记录文件 mtime，保存时若文件已被改动（比如 OAS 回写了）会**拒绝保存**并提示重新加载
4. **只动目标列表**：只重写该任务的 `*_list_N` 和对应计数字段，其它字段原样保留

## 已知限制

- 只能管理**本地或局域网**上的 OAS 目录，不能管理 OAS 正在运行且已独占的文件（Windows 上少见）
- 切号任务的 `current_index` 只在越界时归零，不做"智能修正"——重排后指针位置的含义变了，但脚本有自己的进度语义
- `trigger_all_enabled_tasks` 只读不改，要改请去 OAS 界面
- 独立窗口模式下窗口位置记忆只对 `--app` 有效，普通浏览器标签页由浏览器管理
